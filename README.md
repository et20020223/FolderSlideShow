# 資料夾隨機放映 FolderSlideShow

Windows 10／11 的照片、影片混合放映工具。從資料夾右鍵啟動，自動包含子資料夾，隨機播放照片與影片。支援靜態及動態 WebP，單擊播放畫面即可換下一個。深色介面搭配圓角按鈕和薄進度條，全螢幕時滑鼠靠近上下邊緣才顯示選單。

## 下載與安裝

1. 在本頁點 **Code → Download ZIP**，下載後先將 ZIP **全部解壓縮**。
2. 開啟解壓縮後的資料夾，雙擊 **Install.cmd**。
3. 安裝完成後，對照片資料夾按右鍵，選 **隨機放映（含子資料夾）**。

Windows 11 使用新版右鍵選單時，先選 **顯示其他選項**；使用舊版選單時可直接看到項目。也能在資料夾內空白處或磁碟機上按右鍵啟動。

安裝不需要系統管理員權限，僅加入目前使用者的右鍵選單、桌面捷徑和「傳送到」入口。程式放在：

```text
%LOCALAPPDATA%\Programs\FolderSlideShow
```

**照片及 WebP 不需要另外安裝編解碼器。播放影片需要先安裝 [64 位元 VLC 3.x](https://www.videolan.org/vlc/)，使用預設位置 `C:\Program Files\VideoLAN\VLC`。** 也可將完整 VLC 目錄放到本程式旁的 `VLC` 子目錄。

### 換電腦

在新電腦下載 ZIP、完整解壓縮，再執行 `Install.cmd` 即可。不要只複製 EXE；WebP 需要隨附的三個 DLL。也可直接複製整份下載內容到新電腦安裝。

### 不安裝直接使用

開啟 `FolderSlideShow.exe` 並選擇資料夾即可。右鍵入口則需要執行安裝程式。

## 使用方式

- **資料夾右鍵 → 隨機放映（含子資料夾）**：播放所選資料夾與所有一般子資料夾。
- **桌面「資料夾隨機放映」捷徑**：開啟後選擇資料夾。
- **資料夾右鍵 → 傳送到 → 隨機放映（含子資料夾）**：備用啟動方式。

預設為隨機、循環播放，每張照片顯示 **5 秒**，影片完整播完再換下一個。照片間隔可選 2、3、5、8、10、15、30、60 秒。隨機播放每輪不重複，檔案超過一個時，也避免上一輪最後一個和下一輪第一個相同。

照片保持比例完整顯示，支援 JPEG 方向資訊。影片可拖曳進度條。播放偏好儲存在程式旁的 `settings.ini`。

### 全螢幕選單

全螢幕時，上下選單預設隱藏，包括暫停時。滑鼠靠近頂端會顯示檔名等資訊，靠近底端會顯示播放控制；離開約 0.3 秒後收起。操作下拉選單或拖曳進度／音量時會保持顯示。選單覆蓋在畫面上，不會縮小照片或影片。

### 滑鼠操作

在照片或影片畫面上單擊滑鼠左鍵，就會切換到下一個檔案；暫停時也能手動換圖並維持暫停。點選控制列按鈕、拖曳進度條或音量不會觸發換圖。全螢幕切換請使用 F11／F 或控制列按鈕。

在播放畫面按滑鼠右鍵，可選擇「全螢幕」、「視窗」或「關閉」。目前的顯示模式會打勾，照片和影片都能使用；選單開啟時按 Esc 只會收起選單。

### 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| 空白鍵 | 暫停／繼續 |
| ←／→ | 上一個／下一個 |
| F11 或 F | 切換全螢幕／視窗 |
| S | 切換隨機／依序 |
| L | 開關循環 |
| M | 靜音／取消靜音 |
| ↑／↓ | 調整音量 |
| Ctrl+O | 選擇另一個資料夾 |
| Esc | 結束放映 |

## 格式與系統需求

- **系統**：64 位元 Windows 10／11，.NET Framework 4.x。
- **照片**：JPG、JPEG、JPE、PNG、BMP、GIF、TIF、TIFF、WebP。
- **WebP**：透明、無損／有損、靜態與動態，使用隨附的 libwebp 解碼。
- **影片**：MP4、M4V、MOV、MKV、AVI、WMV、WebM、MPG、MPEG、MTS、M2TS、TS、3GP、FLV、VOB、OGV；實際播放取決於 VLC 對檔案編碼的支援。

## 行為與限制

- 遞迴掃描一般子資料夾；略過無法讀取的目錄和損壞或無法解碼的媒體。
- 不跟隨 junction 或目錄符號連結，避免循環掃描及讀取資料夾樹以外的內容。
- 檔案清單在開啟時建立。新增照片後，重新選擇資料夾以更新清單。
- 「上一個」依實際觀看紀錄返回，最多保存最近約 2,000 次。
- 動態 WebP 依原本影格時間播放，會隨暫停鍵一起暫停；到達照片間隔後仍切換到下一個檔案。單張 WebP 上限為 6,400 萬像素。
- GIF 可顯示動畫，但暫停只停止換圖，不會停止 GIF 本身的動畫。
- 此版本不支援 HEIC、AVIF、RAW。

程式只在本機讀取所選媒體，不修改照片或影片，也不會上傳內容。播放中的檔案可能暫時被鎖定，切換或結束後釋放。

## 疑難排解

**右鍵看不到項目：** 確認已完整解壓縮，從 Windows 檔案總管雙擊 `Install.cmd`，再重新開啟右鍵選單。Windows 11 新版選單需先選「顯示其他選項」。可先使用桌面捷徑或「傳送到」入口。

**WebP 無法播放：** 確認 EXE 旁有 `libsharpyuv.dll`、`libwebp.dll`、`libwebpdemux.dll`，或重新執行安裝。

**影片無法播放：** 確認已安裝 64 位元 VLC 3.x，再用 VLC 本身測試該影片是否能正常播放。

**想改成視窗啟動：** 從命令列執行 `FolderSlideShow.exe --windowed "資料夾路徑"`，或播放時按 F11。

## 移除

在安裝目錄執行 `Uninstall.cmd`，移除本程式的右鍵選單、桌面捷徑和「傳送到」入口。程式檔案及設定會保留；需要時，關閉播放器後自行刪除安裝目錄。你的照片與影片不受影響。

## 原始碼與測試

執行 `Build.ps1`，使用 Windows 內建的 .NET Framework C# 編譯器產生 x64 EXE，不需要 Visual Studio。儲存庫也附有可直接使用的 EXE 與 WebP DLL。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

- `tests/Prepare.ps1`：需將 FFmpeg 加入 PATH；產生合成照片／影片，驗證遞迴掃描、洗牌、歷史紀錄及循環。環境不允許建立 junction 時，該項檢查會明確略過。
- `tests/TestWebp.ps1`：需 Python 與 Pillow；產生合成 WebP，驗證色彩、透明、動畫時間、循環及子資料夾掃描。
- 開發追蹤：`FolderSlideShow.exe --windowed --trace trace.log "資料夾路徑"`。一般使用不會產生播放紀錄。
